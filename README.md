# для тебя

Маленький лендинг-сюрприз. Деплой на GitHub Pages.

## Как опубликовать

1. Создать новый репозиторий на GitHub (например, `for-her` или любое другое имя)
2. Загрузить туда **всё содержимое этой папки** (`index.html` + папку `img/`)
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` → `/(root)` → Save
4. Через 1–2 минуты сайт будет доступен по адресу `https://<твой-username>.github.io/<имя-репо>/`

## Пасхалки внутри

1. **Konami code** — на клавиатуре `↑ ↑ ↓ ↓ ← → ← → B A` → запускает дождь сердечек + секретное окно
2. **Слова-триггеры** — просто напечатать на странице (можно где угодно):
   - `love` · `лето` · `kotik` · `kiss` · `celuy`
3. **Сердечко в футере** — кликнуть 7 раз
4. **URL-хеши** — добавить в конец адреса:
   - `#навсегда` · `#тыкрасивая` · `#beautiful` · `#привет` · `#hi`
5. **Правый верхний угол страницы** — навести курсор → появится «я тут ❤»
6. **DevTools / Console** (F12) — там приветствие от меня
7. **Любой клик** по странице — оставляет крошечное сердечко

## Что отредактировать (опционально)

Открой `index.html` и найди:
- `made with ❤ · 2026` в футере → можно поставить дату
- Текст письма в секции `<section class="letter">` → допиши своё
- Цифры в счётчиках (`data-target="365"`) → подставь реальное количество дней
- Триггер-слова в JS → можно добавить её имя как слово-пасхалку
